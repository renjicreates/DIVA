## DIVA — Fashion & Lifestyle Brand

Welcome to **DIVA**, a fashion and lifestyle website created to showcase elegant fashion, luxury accessories, jewellery, handbags and beauty products.

## 🌸 About the Project

DIVA is a website project designed to present fashionable products through an attractive and user-friendly interface. It features product collections, brand information and contact details.

## 📁 Project Files

| File | Description |
|---|---|
| `index.html` | Main entry point for the website. |
| `Diva.html` | Main DIVA homepage. |
| `Diva.js` | JavaScript functionality for the homepage. |
| `diva.css` | Styling and visual layout for the homepage. |
| `Products.html` | Products page displaying available collections. |
| `products.js` | JavaScript functionality for the products page. |
| `About Us.html` | Information about the DIVA brand. |
| `Contact us.html` | Contact page for visitors. |

## 🛍️ Product Categories

- Jewellery and bracelets
- Luxury handbags
- Fashion accessories
- Beauty and lifestyle products

## 🛠️ Technologies Used

- HTML5 — Website structure.
- CSS3 — Website styling and layout.
- JavaScript — Website interactivity.
